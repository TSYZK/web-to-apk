============================================================
 网页转 APK 打包工具  使用说明
============================================================

【这是什么】
一个 Windows 桌面程序：输入一个网页地址，先检测该网页能不能正常
打开，中间区域直接预览网页，然后一键把它打包成安卓手机 APK 安装包。
打包出的 App 用原生 WebView 加载你的网址，和普通 App 一样安装使用。

【怎么启动】
双击运行：  启动打包程序.bat
（首次启动会自动安装界面依赖，约 200MB，需联网，耐心等待即可）

【操作步骤】
1. 左侧「① 网页地址」输入网址，例如 https://m.example.com
   点击「检测网页」：
     - 绿灯 = 网页可以正常打开（显示 HTTP 状态、响应耗时）
     - 红灯 = 打不开，按提示排查（网址错误 / 服务器不可达）
   中间区域会同时加载、预览该网页（可前进/后退/刷新）。

2. 「② 应用配置」填写：
     - 应用名称：手机桌面图标下显示的名字
     - 包名：形如 com.company.myapp（检测成功后会自动建议一个）
     - 版本号 / 版本名
     - 主题色：状态栏与图标底色（点击色块选择）
     - 应用图标：可自选一张方形图片（PNG/JPG），不选用默认图标
     - 全屏、保持屏幕常亮：按需勾选
     - 构建类型：release 正式版（默认，可直接发给别人安装）

3.「③ 构建环境」：
   真正生成 APK 需要 JDK17 + Android SDK + Gradle（共约 700MB）。
   点击「一键安装构建环境」，程序会自动从国内镜像下载配置，
   不影响系统，全部放在本程序 workspace\tools 目录内。
   已安装过则显示“环境已就绪”。

4. 点击「④ 开始打包 APK」，右侧实时显示：
     - 4 个步骤的状态（检测网页 / 生成工程 / 准备环境 / 编译打包）
     - 总体进度条
     - 深色窗口内的实时构建日志
   打包成功后 APK 保存在：
     workspace\apks\  目录
   可点「打开 APK 所在文件夹」，或手机开启 USB 调试连线后点
   「安装到手机」直接 adb 安装。

【生成的文件都在哪】
  workspace\projects\   每个 App 的完整 Android 工程源码
                        （可用 Android Studio 打开做二次开发）
  workspace\apks\       打好的 APK 安装包
  workspace\tools\      自动下载的 JDK / SDK / Gradle

【常见问题】
Q：打包出的 App 打开是空白？
A：确认手机能联网；若网址是 http 明文或自签名证书，程序已默认
   允许；部分站点做了移动端 UA 限制，可用手机浏览器先验证。

Q：环境安装失败？
A：多为网络波动，直接重新点「一键安装」，已下载好的部分会复用；
   公司/校园网络可能拦截，可换网络重试。

Q：想要“完全离线、不联网也能打开”的 App？
A：当前版本为在线网址模式（与 PWABuilder 同类）。工程源码已生成，
   可将网页静态资源放入 app\src\main\assets 后改为本地加载。

Q：APK 怎么发给别人？
A：release 版已自动签名，把 workspace\apks 里的 apk 通过微信/QQ/
   网盘发送，安卓手机点击安装（需允许“安装未知来源应用”）。
